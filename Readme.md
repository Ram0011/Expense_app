# Expense Tracker App

A modern **Expense Tracker** application to manage your personal finances. Easily add, update, and delete expenses while keeping track of spending habits.

---

## 🌟 Features

-   **Add, Edit, Delete Expenses** – Track your expenses with ease.
-   **Categorized Expenses** – Organize your spending by categories like Food, Rent, Entertainment, etc.
-   **Responsive Design** – Works seamlessly on mobile, tablet, and desktop.
-   **Animations** – Smooth transitions and interactions using **Framer Motion**.
-   **Interactive UI** – Built with **Ant Design** components for a polished user experience.
-   **Tailwind CSS Styling** – Clean, modern, and fully customizable styling.

---

## 🖥 Tech Stack

### Frontend

-   **React.js** – JavaScript library for building user interfaces.
-   **Tailwind CSS** – Utility-first CSS framework for responsive design.
-   **Framer Motion** – Animations and motion effects.
-   **Ant Design** – Component library for UI elements.

### Backend

-   **Node.js** – JavaScript runtime for server-side development.
-   **Express.js** – Web framework for handling REST APIs.
-   **MongoDB** – NoSQL database for storing expense data.

---

## ⚙️ Installation

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm start
```

## 🔧 Features in Detail

-   **Add Expense** – Add new expenses with amount, date, description, and category.
-   **Edit Expense** – Update existing expense details.
-   **Delete Expense** – Remove an expense permanently.
-   **Expense Categories** – Food, Rent, Entertainment, Transportation, Health, Education, Shopping, Other.
-   **Animated UI** – Smooth transitions and hover effects using Framer Motion.
-   **Responsive Design** – Works well across all device sizes.

---

## 📌 Usage

1. Start the backend server.
2. Start the frontend React app.
3. Open the app in your browser.
4. Add, edit, or delete expenses and track your spending.
